            URL Web App Apps Script

            URL diperoleh setelah men-deploy Code.gs sebagai Web App (lihat PANDUAN-DEPLOY.md, langkah 4). URL disimpan di browser Anda, tidak ada token/password di dalam kode. Bila muncul "Koneksi ke Web App gagal", gunakan kartu Diagnostik Koneksi di bawah.

            Jadikan URL Permanen — otomatis di semua browser & perangkat

            URL dari tombol Simpan URL hanya berlaku di browser ini (localStorage). Agar tidak perlu mengatur ulang saat ganti browser atau ganti perangkat, tanam URL ke dalam file script.js — URL akan menyertai file website di hosting dan otomatis dipakai semua pengunjung:

            1. Isi URL di atas, klik Simpan URL, dan pastikan Uji Koneksi hijau.
            2. Klik Salin Kode Permanen di bawah.
            3. Buka script.js → temukan baris WEB_APP_URL: '', di bagian atas (CONFIG) → tempel kode yang disalin menggantikan baris itu.
            4. Simpan, lalu unggah ulang script.js ke hosting (GitHub Pages/Netlify) atau perbarui folder lokal.
            5. Selesai — semua browser & perangkat otomatis terhubung, tanpa membuka Pengaturan.
            Sumber URL: belum diperiksa
            Diagnostik Koneksi & Konfigurasi Deploy

            Menjalankan 4 pemeriksaan berurutan: (1) Internet → (2) Format URL → (3) Jalur GET (baca data) → (4) Jalur POST (simpan/unggah). Jalankan kartu ini setiap kali muncul "Koneksi ke Web App gagal" saat menyimpan — aplikasi menunjukkan titik gagalnya beserta langkah perbaikan konfigurasi deploy.
